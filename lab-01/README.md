# Лабораторная работа № 1

**Тема:** Объектная модель симулятора космического передвижения

**Дисциплина:** Объектно-ориентированное программирование

## Описание

Проект представляет собой объектную модель симулятора космических перелётов, разработанную на C# с применением принципов ООП.

Программа моделирует прохождение маршрутов различными кораблями с учётом характеристик двигателей, свойств космической среды, препятствий и состояния защитных систем.

Основные возможности:

- Расчёт времени перелёта и расхода двух видов топлива.
- Моделирование взаимодействия кораблей с препятствиями.
- Учёт повреждений корпусов и дефлекторов.
- Определение результата прохождения составного маршрута.
- Выбор оптимального корабля по стоимости топлива с учётом времени перелёта.

## Технологии

- C# / .NET 8
- xUnit — модульное тестирование
- Visual Studio 2022

## Архитектура

Проект разделён на две части:

**Lab1** — библиотека классов, реализующая предметную область и алгоритмы симуляции.

**Lab1Tests** — набор модульных тестов, проверяющих отдельные компоненты и комплексные сценарии.

Основная логика сосредоточена в `RouteSimulator`. Класс последовательно обрабатывает участки маршрута, рассчитывает параметры движения и взаимодействие с препятствиями.

Для выбора наиболее экономичного корабля используется `OptimalShipSelector`.

Архитектура основана на композиции объектов, интерфейсах, наследовании и полиморфизме.

## Тестирование

В проекте реализованы модульные тесты компонентов и семь сценариев, предусмотренных заданием лабораторной работы.

Для запуска тестов откройте `Lab1.sln` в Visual Studio и воспользуйтесь обозревателем тестов (Test Explorer).

Альтернативный запуск через .NET CLI из каталога лабораторной:

`dotnet test Lab1.sln`
